If you only see this box, the app is not running through Vite. The VS Code Live Server extension cannot compile main.ts from the project root.

Recommended:

  1. Terminal in this folder: npm install (once)
  2. npm start
  3. Open the URL shown (e.g. http://localhost:5173)

Live Server: run npm run build, then open dist/index.html with Live Server (use the dist folder as the server root).
