# Social Media Maker

Create posts, stories, app logos, profile pictures, and Facebook covers for Instagram, TikTok, Threads, Facebook, and WhatsApp.

## How to use

1. Open `index.html` in your browser.
2. Choose an **Asset Type** (feed post, story, logo, profile picture, or Facebook cover).
3. Set a **Background** (solid color or image with optional blur).
4. Add **Overlay Images** and **Text** as needed.
5. Drag elements on the live preview to position them.
6. Choose **PNG** or **JPEG** and click **Download**.

## Profile picture mode

Upload a photo in the **Profile photo** slot. The image fits inside a circle on your chosen background color. The exported file is a square PNG/JPEG with solid background outside the circle (no transparent corners).

## Tips

- Use **Feed Posts** presets when posting the same square design to Instagram, TikTok, Threads, and Facebook.
- For profile pictures, pick a background color that matches your brand.
- Use **Fit image (contain)** on overlay slots when you want the full image visible without cropping.
- Drag corner handles on selected images to resize.
